# VoltForge 公司经营模拟

面向中学生社团的多人公司经营模拟。团队通过同一网站注册公司并提交每轮经营决策，管理员统一结算和公布结果。

## 功能

- 不同设备共享公司、轮次、决定和报表数据
- 8轮市场事件与统一市场竞争
- 生产、定价、工资、设备、研发、营销、贷款和还款决策
- 真实利润表、现金流量表、资产负债表和经营明细
- 估值折线、公开排名与管理员分析
- 付费购买其他公司上一轮部分情报
- 管理员管理提交、密码、公司、结算、公布、导出与重置

## 运行检查

运行 npm run build、npm run check 和 npm test。

正式部署需要 INVITE_CODE、ADMIN_PASSWORD、SESSION_SECRET 三个服务器环境变量，真实值不要提交到 GitHub。
